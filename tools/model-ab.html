Legacy JSON vs converted glTF

Sprint S3's per-model visual A/B. The left frame loads the original models/js/*.js through three r98's JSONLoader — the code path the app used before this sprint. The right loads models/js-glb/*.glb through GLTFLoader and the new mergeMeshes pipeline, including the legacy texture-encoding restoration. Same camera, same lights, same framing.

Shape is asserted numerically in tests/model-conversion.test.js; this page is for the half a test cannot judge. Lambert has no exact PBR equivalent, so the standard is accepted, not identical — look for wrong textures, missing surfaces, inverted UVs and gross brightness shifts, not for a subtle change in the specular falloff.

This page only works while r98 is the engine. S4 deletes JSONLoader, and the left column with it.
